# Gap Priority Rubric

- `P0 blocking`: claim cannot be made without fixing this gap.
- `P1 important`: likely reviewer concern; fix if feasible before submission.
- `P2 useful`: improves confidence but not required for current claim strength.
- `P3 optional`: future work or discussion-level limitation.

Cost classes:

- `low`: text change, table lookup, existing output audit.
- `medium`: rerun existing script, add sensitivity check, create source table.
- `high`: new dataset, new pipeline, wet-lab validation, large compute job.
