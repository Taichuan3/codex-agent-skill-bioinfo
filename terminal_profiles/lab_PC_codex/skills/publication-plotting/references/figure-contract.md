# Figure Contract

Use before writing plotting code or editing a manuscript figure.

## Required fields

```text
Core conclusion:
Output target: paper / PPT / internal report
Figure archetype:
Backend: Python / R / existing file edit
Final size:
Panel map:
Evidence hierarchy:
Statistics needed:
Source data needed:
Visual risks:
Reviewer risk:
Exports: PNG + SVG by default
```

## Panel rules

- Each main figure should carry one dominant claim.
- Every panel needs one primary role: definition, main evidence, validation, robustness, case illustration, or limitation.
- If removing a panel does not weaken the argument, demote it or remove it.
- The visually strongest panel should carry the strongest evidence, not the prettiest output.
- Keep controls and robustness visually quieter than primary evidence.

## Main versus supplement

Keep in the main figure:

- evidence required for the central claim
- key comparison readers must see immediately
- definitions needed to interpret later panels

Move to supplement:

- secondary robustness variants
- dense method comparisons
- extended cases
- extra examples that support but do not define the claim
