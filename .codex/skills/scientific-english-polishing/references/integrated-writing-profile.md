# Integrated scientific English profile

## Priority and scope

Default for substantive English scientific editing and Chinese-to-English
scientific translation. Fidelity and evidence boundaries come first, followed by
explicit user/project requirements, verified target-journal rules, then this
profile. It is a local synthesis, not an official Nature or Hashimoto template.
Do not force full restructuring on spelling-only or literal-translation requests.
Do not invent prose from absent results; flag missing inputs instead.

## Shared style

- Start from the reader's scientific question and the concrete biological object.
  Develop one main function per paragraph: question, necessary design, decisive
  observation and bounded interpretation. Adapt the sequence rather than filling
  four mandatory sentences.
- Use figures as evidence anchors when provided, not decorative citations.
  Retain the numbers, denominators, statistical units and uncertainty needed to
  understand the result. Never guess figure numbers or merge different cohorts.
- Keep terms stable. Use direct verbs for observations; qualify prediction,
  association and hypotheses. Strong prose does not mean stronger claims.
- Preserve sourced preliminary results, exceptions and negative observations.
  “Not significant” is not equivalence; model performance is not causality.
- For every added explanation, ask what redundant sentence can be replaced or
  removed. Never delete a caveat, necessary QC or reproducibility information
  merely to shorten the manuscript.
- Keep logs, internal paths and workflow status outside reader-facing prose.
  Preserve exact provenance in existing project records; do not change paths,
  manifests, GUIDE, source data or analysis under a language-editing request.

## Section functions

| Section | Default function and boundary |
|---|---|
| Title | Concrete object and supported finding; no invented mechanism or superlative |
| Abstract | Problem/gap, approach, main evidence and bounded significance; not a data inventory |
| Introduction | Minimum background, unresolved question and rationale; a brief study overview is allowed, not a detailed Results replay |
| Results | One question at a time, necessary design and QC, figure-linked observations, exceptions and limited interpretation |
| Discussion | Interpret the main answer, compare supplied evidence, evaluate alternatives and limitations; do not repeat every result or invent citations |
| Methods | Preserve sample definitions, versions, parameters, filters and statistics; style cannot remove replication details |
| Caption | For existing captions preserve panels, units, n, tests and caveats; new information contracts belong to figure-caption |
| Response letter | Address the actual concern and distinguish completed changes from proposed work; do not force abstract/Results architecture |

Headings, word limits, citation formats and figure references follow the user's
project and target journal. Neither “no subheadings” nor a particular paragraph
length is a universal author or journal rule. Translation first preserves the
source meaning; structural compression beyond fidelity requires the requested scope.

## Delivery and acceptance

Return a usable revision, with brief risk/terminology notes only when needed.
Check source-to-revision numbers, direction, units, sample sets, figure pointers,
negative findings, caveats and claim strength. State whether source data were
actually inspected; language QA is not scientific validation.
