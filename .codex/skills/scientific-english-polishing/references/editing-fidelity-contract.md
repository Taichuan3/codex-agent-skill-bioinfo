# 三模块共用：编辑保真契约

适用于中文修改、中译英和英文润色；Hashimoto 保持独立。风格参考服从本契约。保真不是逐字复原，也不是确认作者主张已经科学验证。

## 先确定操作和层级

- 从证据起草新主张：不得发明新颖性、机制、因果或优先权；只写材料支持的内容。
- 修改已有作者主张：双向保留因果性、确定性、新颖性、适用范围与作者立场。缺少完整证据附件不等于主张不成立，不因此把 reveal 改成 suggest、causal 改成 associated、new algorithm 改成 algorithm。
- `light`：普通润色和翻译默认值；只做段内语言调整，保留段落归属、论证次序与章节。不跨段移动证据；结构问题单列。
- `structural`：用户要求重组、整节重写或恢复打乱文本时采用，简短说明所用层级，无需另设审批。可成组移动论点、证据、限制和引用，但不能猜测缺失关系。更窄的用户范围始终优先。
- 英文拼写为参数：按用户/目标期刊选择 US 或 UK，否则沿用输入主要体例；不强制美式。

## 强度、修辞与风险分开

| 类型 | 例子 | 编辑方法 |
|---|---|---|
| 实质主张标记 | 新的、首次、揭示、导致、确实如此、前所未有 | 保留其语义强度与范围，不要求原词逐字出现 |
| 空泛强调 | 很多很多、非常、特别、其实 | 无信息时可删；“极低浓度”等承载程度的表达不能按词表删除 |
| 作者论证立场 | 最重要的是、天真的假设、我们提出 | 保留主次、评价对象与作者贡献，不一律改成无人称谨慎摘要 |

怀疑主张过强时，保留作者原表述的可追溯版本，在独立核对项说明具体疑点，必要时给清楚标记的保守替代表述；不得静默替换。输入明确矛盾（如仅相关却称完全证明因果）时，将受影响句标为待作者解决，不把它作为无条件定稿交付；保留原句及替代建议的对应关系，继续完成其他内容。没有矛盾时，不为每个 new 或 reveal 强制索取证据或确认。

## 保留论证，而不只保留数字

- 保留问题/假设 → 检验 → 发现 → 新问题的功能及时间关系；“反常/矛盾”若是下一步实验的动机不能去掉，也不能改成事后解释。不虚构预注册或事前假设。
- 保留枚举的概念数量、分组、主次及贡献定位。四项改进不能压成三类或普通操作清单；无需强制 (i)–(iv) 排版。
- 作者发现、提出、归因的声音，以及限制之所以限制哪条推断，都应可辨认；不机械要求每句第一人称。
- 引用绑定到它支持的具体子论断，不只核对编号是否还在。拆句、换段时保留绑定与限定；未核验文献时不声称已核验其支持范围。
- 衔接词必须来自输入的逻辑；不得凭空添加 therefore、时间跨度或因果。输入已有“另一个模型”时 another model 可以正确，不按词禁用。
- 实验目的不是已证实效果：to reduce aggregation 不能变成 reduced aggregation。方向、否定、条件、范围和不确定性也逐项锁定。
- 术语按领域概念核对；不拼接两种病名，不把 rollout 与 MCTS、collision 与 contamination 无依据互换。无法唯一确定时标记歧义，不猜回原论文。外部术语核验须符合用户范围，不以偷看原文补回缺失内容。

## 每阶段交接

内部保留轻量锚点：事实数字、主张各维度、论证/枚举、引用子句、术语与待核对项。中文→翻译→末轮英文均回对上一阶段和获准中文；不把核对表强制塞进正文。可追溯的问题清单随阶段传递，不把未决句悄悄恢复成定稿。语言核对不等于科学验证或发表保证。
