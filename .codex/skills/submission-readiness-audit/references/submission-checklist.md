# Submission Checklist

## Blocking

- Every main claim maps to figure/table/source data/citation.
- Main text numbers match figures, legends, methods, and supplementary tables.
- Methods include data source, reference version, software version, key parameters, filtering rules, and statistics.
- Source data files exist for main figure panels.
- Code or notebooks can regenerate core tables and figures.
- Data/Code Availability statements are specific.

## Important

- Abstract does not overstate exploratory results.
- Introduction does not promise a mechanism that Results cannot prove.
- Discussion separates supported conclusions from hypotheses.
- Figure legends include n, filtering status, statistical test, and caveat where needed.
- Supplementary tables are named and discoverable.
