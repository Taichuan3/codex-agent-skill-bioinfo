# Validation Matrix

| Validation type | Best for | Cannot prove | Typical output |
|---|---|---|---|
| Sensitivity check | Robustness to parameters | Biological mechanism | robustness table |
| Matched/null background | Enrichment specificity | Causality | null distribution |
| Independent cohort | Replication or external validity in the tested cohort/setting | Cross-population or cross-setting generalizability; mechanism | replication figure |
| Orthogonal assay | Measurement consistency | Full causal chain | validation panel |
| Perturbation experiment | Functional relevance | All upstream causes | experimental evidence |

## Common pseudo-validation

- Repeating the same method on the same data without an independent perturbation or sensitivity axis.
- Citing a database annotation derived from the same source evidence as independent support.
- Selecting favorable parameters after seeing the result without reporting the search.
- Calling another correlated assay mechanistic or causal confirmation.
- Treating a non-significant result as proof of no effect without power or equivalence analysis.

## Claim outcomes

| Result | Maximum safe wording |
|---|---|
| Robustness only | Robust association or computationally stable observation |
| Independent replication | Replicated or externally validated association in the tested cohort and setting |
| Orthogonal functional support | Functionally supported candidate relationship |
| Controlled perturbation with alternatives addressed | Causal or functional support within the tested system; mechanistic support only when the specified mediator chain is directly tested |
| Validation infeasible or failed | Exploratory observation, candidate, or hypothesis |
