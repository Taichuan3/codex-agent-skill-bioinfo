# Validation Matrix

| Validation type | Best for | Cannot prove | Typical output |
|---|---|---|---|
| Sensitivity check | Robustness to parameters | Biological mechanism | robustness table |
| Matched/null background | Enrichment specificity | Causality | null distribution |
| Independent cohort | Generalizability | Mechanism alone | replication figure |
| Orthogonal assay | Measurement consistency | Full causal chain | validation panel |
| Perturbation experiment | Functional relevance | All upstream causes | experimental evidence |
