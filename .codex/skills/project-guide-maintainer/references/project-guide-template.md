## 使用建议

- 每次更新时压缩旧信息，不追加流水账。
- 操作命令、运行日志和详细输出路径放到 `PROJECT_PLAN.md` 或对应 summary。
- 如果某个 result 已经很成熟，可以把它写成论文结果段骨架。
- 如果某个 result 仍是探索性，只保留为候选路线并标注证据等级。
