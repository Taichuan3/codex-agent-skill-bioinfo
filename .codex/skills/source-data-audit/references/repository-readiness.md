# Repository Readiness

## Repository choice

1. Use a mandated repository for the data type.
2. Prefer discipline-specific repositories.
3. Use trusted generalist repositories only when no field repository fits.
4. Avoid personal websites, temporary cloud links or private drives as the only route.

## Before submission

- DOI/accession or stable link resolves.
- Title and file names match manuscript terminology.
- Licence/access conditions are explicit.
- README explains columns, units, missing values and transformations.
- Figure source data map to panels.
- Restrictions match manuscript wording.
- Private reviewer links have been tested outside the author account.

## For reused public data

- Cite the original dataset or accession.
- Record exact version/date accessed.
- Record any filtering or transformation.
